# DroneC2 요구사항 정의서

- 버전: v0.1 (초안)
- 상태: 작성 중 — 구현 진행에 따라 갱신 예정

## 1. 개요 및 목표

DroneC2는 **Unity 기반 드론·전차 GPS 위치 및 작전 상황 3D 관제 시스템**이다.
포트폴리오 목적의 프로젝트이며, 가상 데이터로 다수 유닛의 위치와 상태를 3D 지형 위에서 실시간으로 확인하는 관제 화면을 구현한다.

### 목표

1. 가짜 GPS 데이터로 유닛의 이동과 경로를 3D 공간에 표시한다.
2. 실제 지형(Cesium) 위에서 위경도 좌표가 정확히 매핑되도록 한다.
3. 다수 유닛을 관제 UI로 선택·조회·추적할 수 있게 한다.
4. 데이터 소스를 교체해도(가짜 GPS → MAVLink 시뮬레이터) 표시 계층이 변하지 않는 구조를 만든다.

## 2. 기능 요구사항

우선순위: **상** = 단계 완료에 필수, **중** = 권장, **하** = 여유가 있을 때

| ID | 요구사항 | 우선순위 | 단계 |
|---|---|---|---|
| FR-001 | 가짜 GPS 생성기가 위경도·고도·방위·속도를 주기적으로 생성한다. | 상 | 1 |
| FR-002 | 평면 위에서 드론이 GPS 값에 따라 이동한다. | 상 | 1 |
| FR-003 | 드론의 이동 경로(궤적)를 선으로 표시한다. | 상 | 1 |
| FR-004 | 웨이포인트 기반 시나리오(JSON)를 불러와 이동을 재생한다. | 중 | 1 |
| FR-005 | 위경도(WGS84)를 Unity 월드 좌표로 변환한다. | 상 | 1 |
| FR-006 | Cesium 실제 지형 위에 유닛을 배치하고 이동시킨다. | 상 | 2 |
| FR-007 | 지형 고도에 맞춰 지상 유닛(전차)의 높이를 보정한다. | 중 | 2 |
| FR-008 | 다수의 드론·전차 유닛을 동시에 표시한다. | 상 | 3 |
| FR-009 | 유닛 목록 UI에서 유닛을 선택하면 지도 위 해당 유닛으로 포커스한다. | 상 | 3 |
| FR-010 | 선택한 유닛의 상태(위치, 고도, 속도, 방위, 통신 상태)를 표시한다. | 상 | 3 |
| FR-011 | 유닛 종류(드론/전차)와 상태(정상/경고/두절)를 아이콘·색상으로 구분한다. | 중 | 3 |
| FR-012 | 유닛별 카메라 영상 패널을 표시한다. (가상 카메라 또는 샘플 영상) | 중 | 4 |
| FR-013 | 카메라 패널을 여러 개 배치하고 전환할 수 있다. | 하 | 4 |
| FR-014 | MAVLink 시뮬레이터(예: SITL)의 텔레메트리를 수신해 유닛에 반영한다. | 상 | 5 |
| FR-015 | 데이터 소스를 가짜 GPS와 MAVLink 사이에서 설정으로 전환한다. | 중 | 5 |

## 3. 비기능 요구사항

| ID | 항목 | 기준 (초안) | 우선순위 |
|---|---|---|---|
| NFR-001 | 성능 | 유닛 10기 표시 시 일반 PC에서 60 FPS를 목표로 한다. (측정 후 조정) | 중 |
| NFR-002 | 구조 분리 | 데이터 소스·좌표 변환·표시 계층이 인터페이스로 분리된다. | 상 |
| NFR-003 | 확장성 | 새 유닛 종류나 데이터 소스를 기존 코드 수정 최소화로 추가할 수 있다. | 중 |
| NFR-004 | 재현성 | 같은 시나리오 파일로 같은 이동을 재현할 수 있다. | 중 |
| NFR-005 | 좌표 정확도 | 위경도 → 월드 좌표 변환 오차를 테스트로 검증한다. (허용 오차 미정) | 중 |
| NFR-006 | 보안·데이터 | 실제 군사 데이터와 비밀 정보를 저장소에 포함하지 않는다. (6절 참조) | 상 |
| NFR-007 | 문서화 | 각 단계 완료 시 문서와 데모 영상·스크린샷을 갱신한다. | 하 |

## 4. 개발 단계 로드맵

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 1 | 평면 위 가짜 GPS 드론 이동·경로 표시 | 가짜 GPS로 드론이 평면 위를 이동하고 경로가 선으로 그려진다. |
| 2 | Cesium 실제 지형 | 실제 지형 위에서 위경도 기준으로 유닛이 정확한 위치에 표시된다. |
| 3 | 다중 유닛 + 관제 UI | 드론·전차 여러 기가 표시되고 목록 UI로 선택·상태 조회가 가능하다. |
| 4 | 카메라 패널 | 선택한 유닛의 카메라 영상이 패널에 표시된다. |
| 5 | MAVLink 시뮬레이터 연동 | 시뮬레이터 텔레메트리로 유닛이 움직이고 데이터 소스를 전환할 수 있다. |

## 5. 범위 제외

- 실제 무기 체계, 교전·타격 로직, 표적 처리
- 실제 군사 시스템·통신망과의 연동
- 실제 드론·차량에 대한 명령 송신 및 제어 (수신·표시 전용)
- 실제 작전 데이터나 비공개 지형·시설 정보의 사용
- 상용 수준의 인증·권한 관리, 대규모 서버 운영

## 6. 보안 원칙

1. **실제 군사 데이터를 사용하지 않는다.** 모든 위치, 경로, 유닛 식별자는 가상으로 생성한 값이다.
2. **공개 데이터와 가상 데이터만 사용한다.** 지형은 공개 데이터(Cesium 등), 텔레메트리는 시뮬레이터 출력이다.
3. 시나리오·샘플 영상에 실제 시설이나 인물을 식별할 수 있는 정보를 넣지 않는다.
4. API 키·토큰 등 비밀 정보는 저장소에 커밋하지 않는다. (로컬 설정 파일로 분리하고 `.gitignore`에 추가)
5. 외부 서비스(Cesium ion 등)의 이용 약관과 라이선스를 준수한다.
