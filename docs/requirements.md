# DroneC2 요구사항 정의서

- 버전: v0.4 (초안)
- 상태: 작성 중 — 4단계까지 구현 결과 반영, 이후 단계 진행에 따라 갱신 예정

## 1. 개요 및 목표

DroneC2는 **Unity 기반 드론·전차 GPS 위치 및 작전 상황 3D 관제 시스템**이다.
포트폴리오 목적의 프로젝트이며, 가상 데이터로 다수 유닛의 위치와 상태를 3D 지형 위에서 실시간으로 확인하는 관제 화면을 구현한다.

### 목표

1. 가짜 GPS 데이터로 유닛의 이동과 경로를 3D 공간에 표시한다.
2. 실제 지형(Cesium) 위에서 위경도 좌표가 정확히 매핑되도록 한다.
3. 다수 유닛을 관제 UI로 선택·조회·추적할 수 있게 한다.
4. 데이터 소스를 교체해도(가짜 GPS → MAVLink 시뮬레이터) 표시 계층이 변하지 않는 구조를 만든다.

## 4. 개발 단계 로드맵

| 단계 | 내용 | 완료 기준 | 상태 |
|---|---|---|---|
| 1 | 평면 위 가짜 GPS 드론 이동·경로 표시 | 가짜 GPS로 드론이 평면 위를 이동하고 경로가 선으로 그려진다. | 완료 |
| 2 | Cesium 실제 지형 | 실제 지형 위에서 위경도 기준으로 유닛이 정확한 위치에 표시된다. | 완료 |
| 3 | 다중 유닛 + 관제 UI | 드론·전차 여러 기가 표시되고 목록 UI로 선택·상태 조회가 가능하다. | 완료 |
| 4 | 카메라 패널 | 선택한 유닛의 카메라 영상이 패널에 표시된다. | 완료 |
| 5 | MAVLink 시뮬레이터 연동 | 시뮬레이터 텔레메트리로 유닛이 움직이고 데이터 소스를 전환할 수 있다. | 예정 |

### 1단계 구현 결과

| ID | 결과 | 비고 |
|---|---|---|
| FR-001 | 완료 | `FakeGpsSource`가 위경도·고도·방위·속도를 10Hz로 생성 |
| FR-002 | 완료 | 드론이 웨이포인트를 따라 이동하고 진행 방향(방위각)으로 회전 |
| FR-003 | 완료 | `PathTrail`이 지나간 경로를 선으로 표시 (2m 간격, 최대 2000점) |
| FR-004 | 미구현 | 시나리오 JSON 로딩은 후속 작업. 현재 웨이포인트는 인스펙터에서 입력 |
| FR-005 | 완료 | `LocalTangentPlaneConverter`(평면 근사), EditMode 테스트 7건 통과 |

추가로 추적 카메라(`FollowCamera`)와 표시용 드론 확대(시각 요소만 4배, 위치·회전 계산 무관)를 적용했다.
1단계 기준점은 실제 시설과 무관한 공해상 좌표(30.0°N, 40.0°W)이다. 2단계 시연 지역은 그레이트 스모키 산맥 국립공원(미국)이며, 기준점은 아래 "2단계 구현 결과"를 따른다. (6절 참조)

### 2단계 구현 결과

| ID | 결과 | 비고 |
|---|---|---|
| FR-005 | 완료 | `CesiumGeoreferenceConverter`가 `ICoordinateConverter`를 구현. 원점·위도·경도·높이·방위를 EditMode 테스트로 검증(허용 오차 0.5m, 기대값은 WGS84 곡률 반경 공식으로 독립 계산) |
| FR-006 | 완료 | Cesium World Terrain + Bing Maps Aerial 위에서 드론이 위경도 기준 위치로 이동 |
| FR-007 | 완료 | `ITerrainHeightSampler` + 격자 캐시·쌍선형 보간. 드론(`AboveGround` 80m)의 지표 위 높이를 140점 실측해 77.2~81.0m 확인. `ClampToGround`는 고도 해석기 단위 테스트까지 검증했고 지상 유닛(전차) 적용은 3단계 |
| FR-004 | 미구현 | 시나리오 JSON 로딩은 후속 작업. 웨이포인트는 인스펙터에서 입력 |

| 항목 | 값 |
|---|---|
| 시연 지역 | 그레이트 스모키 산맥 국립공원(미국), 클링맨스 돔 부근 |
| 기준점 | 35.563°N, 83.499°W, 지오레퍼런스 높이 2000m(타원체고). 같은 지점 지형 높이 실측 1991.8m |
| 경로 | 기준점 주변 사각형, 위도 ±0.0054°·경도 ±0.0066°(한 변 약 1.2km, 코너까지 약 850m), 속도 25m/s, 한 바퀴 약 192초 |
| 경로상 지형 높이 | 약 1,556~1,992m(9점 샘플), 주행 구간 기록 1,662~1,921m |
| Cesium for Unity | 1.26.0 (Unity 6000.6.5f1, URP 17.6.0에서 컴파일·렌더 확인) |
| 테스트 | EditMode 35건 통과 |

알려진 한계: 지형 높이 조회 지연은 측정하지 못했다. 높이 캐시에 상한이 없다. 고도는 타원체고이며 해발 고도와 약 30m 차이가 난다. 방위 회전은 원점 기준 ENU를 쓰므로 원점에서 멀어지면 곡률 오차가 생긴다(5km에서 약 0.05°).

## 5. 범위 제외

- 실제 무기 체계, 교전·타격 로직, 표적 처리
- 실제 군사 시스템·통신망과의 연동
- 실제 드론·차량에 대한 명령 송신 및 제어 (수신·표시 전용)
- 실제 작전 데이터나 비공개 지형·시설 정보의 사용
- 상용 수준의 인증·권한 관리, 대규모 서버 운영

## 6. 보안 원칙

1. **실제 군사 데이터를 사용하지 않는다.** 모든 위치, 경로, 유닛 식별자는 가상으로 생성한 값이다.
2. **공개 데이터와 가상 데이터만 사용한다.** 지형은 공개 데이터(Cesium 등), 텔레메트리는 시뮬레이터 출력이다.
3. 시나리오·샘플 영상에 실제 시설이나 인물을 식별할 수 있는 정보를 넣지 않는다.
4. API 키·토큰 등 비밀 정보는 저장소에 커밋하지 않는다. (로컬 설정 파일로 분리하고 `.gitignore`에 추가)
5. 외부 서비스(Cesium ion 등)의 이용 약관과 라이선스를 준수한다.
6. **시연 지역은 미국 그레이트 스모키 산맥 국립공원으로 한다.** 보안상 국내 지역, 특히 접경 지역은 의도적으로 제외했다. 한국 산악 지형과 고도(최고 약 2,000m)·숲으로 덮인 능선 지형이 유사해 대체 지역으로 선정했다.
7. **Cesium ion 토큰은 다음 방침으로 관리한다.**
   - DroneC2 전용 토큰을 만들고 권한은 `assets:read`만, 접근 대상은 필요한 지형·이미지 에셋으로 제한한다.
   - 토큰이 저장되는 `Assets/CesiumSettings/Resources/CesiumIonServers/ion.cesium.com.asset`은 `.gitignore`에 추가해 커밋하지 않는다.
   - 토큰은 채팅에 붙여넣지 않고, 사용자가 Unity의 Cesium 패널에서 직접 연결한다.
   - README에 "본인 토큰을 넣어 실행"하라는 안내를 쓴다.
